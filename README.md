# ANR's Aim Assist (anr-aim)

Aim assist for Minecraft 1.21.1 (NeoForge): friction, pull or lock onto mobs, with ballistic
aim for bows and thrown items. Off by default. An add-on of
[ANR's Trackpad & Touchpad Tweaks](https://github.com/augusto-nalin/anr-trackpad-rel).

Some servers see aim assist as cheating: use it where it's allowed.

## Requirements
- Minecraft 1.21.1, NeoForge 21.1+
- **Required:** ANR's Trackpad & Touchpad Tweaks (same Minecraft version)

## Reporting a bug
Open an [issue](../../issues/new/choose) with your Minecraft / NeoForge / anr-aim /
anr-trackpad versions, steps to reproduce, and your `logs/latest.log`.

## About this repository
This repository hosts the issue tracker and `update.json`, which the update checker reads
to show "update available" in the Mods list. The mod's source is not published here.
